About

Hi, I’m Mokin

I’m a System QA Engineer (SDET) at Dell EMC, working on the PowerStore storage platform. My day-to-day work sits at the intersection of storage systems, hardware debugging, and test automation.

What I Do

At Dell EMC, I work as part of the system QA team responsible for validating the reliability, performance, and correctness of the PowerStore all-flash storage array. My work spans:

  • System-level testing — end-to-end validation across hardware and firmware
  • GUI & CLI test automation — building test frameworks with Playwright, Selenium, and Python
  • Storage protocol testing — iSCSI, FC, NVMe-oF, NFS, SMB
  • Hardware debugging — reading logs, tracing failures, correlating storage events
  • Python scripting — building small tools to speed up test analysis and log processing

What This Blog Is About

This is where I document things I learn, problems I solve, and tools I build — mostly for my future self, but hopefully useful to others too.

Topics you’ll find here:

Area Examples
Testing & Automation Playwright vs Selenium analysis, GUI test design, CI integration
Storage & Hardware PowerStore notes, protocol debugging, hardware quirks
Coding & Tools Python scripts, shell utilities, timestamp calculators
Learning & Reflection Tech career notes, podcast summaries (左耳听风), book takeaways
AI & Prompt Engineering Practical prompt frameworks, AI learning notes
English Learning Vocabulary from work and study sessions

Outside Work

Outside of storage and QA, I’m interested in:

  • AI tools and how to use them well (hence the prompt engineering notes)
  • Building better English for technical communication
  • Reading about engineering culture and technical leadership

All views here are my own, not those of Dell Technologies.
